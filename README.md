## Usage

```bash
# List available skins
fortnite-swapper list

# Swap to specific skin
fortnite-swapper swap --skin "skin_name"

# Import custom skin
fortnite-swapper import --file ./custom_skin.zip

# Save profile
fortnite-swapper profile save --name "my_loadout"
```
